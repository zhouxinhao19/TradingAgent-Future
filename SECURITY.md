# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue immediately.
Instead, contact the maintainer privately and describe the problem clearly.

## Expected Handling

- We will review the report promptly.
- We may ask for additional information or a reproduction.
- We will provide a timeline for remediation when possible.

## Sensitive Information

Please do not commit or share any of the following in the repository:

- API keys
- access tokens
- database passwords
- private service endpoints
- internal deployment secrets
