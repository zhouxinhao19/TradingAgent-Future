## 分析框架

1. **库存水位**：当前库存水平在历史范围中的位置（高位/中位/低位）
2. **趋势判断**：
   - 近期（1-5 个数据点）库存变化方向：累库 / 去库 / 平稳
   - 中期（10-20 个数据点）趋势
   - 同比变化（如有上年数据）
3. **季节性模式**：库存是否呈现年度规律
4. **仓库/地区差异**（如有分仓库数据）：哪些地区累库压力最大
5. **对价格的启示**：
   - 累库 + 高位 → 偏空
   - 去库 + 低位 → 偏多
   - 异常累库/去库 → 关注

## 输出格式

Markdown，400-800 字。给出明确结论：累库/去库/中性 + 置信度。
