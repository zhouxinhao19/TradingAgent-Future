## 分析框架

1. **时间范围与频率**：数据的时间跨度、采样频率（日/周/月）
2. **趋势分析**：
   - 整体趋势：上行 / 下行 / 震荡
   - 移动平均线穿越信号（如适用）
   - 动量变化
3. **周期性**：
   - 是否存在明显周期（年/季/月）
   - 季节性模式
4. **波动率与异常点**：
   - 整体波动水平
   - 统计异常点（超过 2σ/3σ）
   - 近期波动率变化
5. **尾部行为**：
   - 最大值/最小值分布
   - 分位数偏移
